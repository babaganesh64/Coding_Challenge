# 💻 Coding Challenges & Practice

A centralized archive of my daily programming practice, focusing on software mechanics, core concepts, and architecture through **Real-World Problem Statements** sourced from various platforms.

## 🎯 Current Focus: Java

I am currently using **Java** to master foundational algorithms, data structures, and problem-solving logic. The primary goal is to build strong muscle memory for standard programming patterns and software design.

## Repository Structure

The repository is organized by core programming concepts to keep everything scalable and easy to navigate as the complexity of the problems grows.

*   **`Arrays_Practice/`** — Array manipulation, traversal, and searching algorithms (e.g., standardizing branding color codes).
*   **`Vectors/`** — Basic to advanced Vector programs.
*   *Coming soon: Sorting, Searching, and lower-level logic...*

## Problem Format

To make this repository easy to read and review, every `.java` file is **entirely self-contained**. 

At the very top of each file, you will find a block comment containing:
*   **Problem Statement**
*   **Example Input**
*   **Example Output**

The executable solution and logic immediately follow the comment block. This structure provides instant context without the need to cross-reference external platforms or websites.
