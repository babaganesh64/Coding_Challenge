# Coding Challenges & Practice

A centralized archive of my daily programming practice, focusing on software mechanics, core concepts, and architecture with Real World Problem Statements from various sources.

## Current Focus: Java
I am currently using Java to master foundational algorithms, data structures, and problem-solving logic. The goal is to build strong muscle memory for standard programming patterns.

## Repository Structure
The repository is organized by core programming concepts to keep everything scalable and easy to navigate as the complexity grows.

* **`Arrays_Practice/`** - Array manipulation, traversal, and searching algorithms (e.g., standardizing branding color codes).
* *(More concepts like Sorting, Searching, and lower-level logic coming soon...)*

## Problem Format
To make this repository easy to review, every `.java` file is entirely self-contained. 
* The **Problem Statement**, **Example Input**, and **Example Output** are included at the very top of each file in a block comment.
* The executable solution and logic immediately follow. 
* This provides instant context without needing to cross-reference external platforms.

## How to Run
Since each file contains its own `main` method, you can compile and run any file independently from the terminal. 

For example:
```bash
javac ThePaletteMatch.java
java ThePaletteMatch
