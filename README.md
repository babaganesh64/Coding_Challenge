*   **`Arrays_Practice/`** — Array manipulation, traversal, and searching algorithms (e.g., standardizing branding color codes).
*   **`Vectors/`** — Basic to advanced Vector programs.
*   *Coming soon: Sorting, Searching, and lower-level logic...*

## Problem Format

To make this repository easy to read and review, every `.java` file is **entirely self-contained**. 

At the very top of each file, you will find a block comment containing:
*   **Problem Statement**
*   **Example Input**
*   **Example Output**
*   **Followed by Solution**

The executable solution and logic immediately follow the comment block. This structure provides instant context without the need to cross-reference external platforms or websites.

## How to Run
